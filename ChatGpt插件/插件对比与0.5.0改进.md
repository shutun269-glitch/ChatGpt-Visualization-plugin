# 对话便笺画布：GitHub 对比与 0.5.0 改进

研究日期：2026-10-28。对比依据是项目公开 README 与本插件源码；未对其他项目做实际安装测评。此次参考其交互思路，未复制其实现代码。

## 同类项目对比

| 项目 | 公开文档中的主要能力 | 我们的相对优势 | 我们仍有的差距 |
| --- | --- | --- | --- |
| [dsh-synapse](https://github.com/liangmianya/dsh-synapse/blob/main/README.md) | 面向 DeepSeek Harness 的会话可视化，利用原生会话/分叉关系，实时投影，支持选中文字追问 | 每张卡片合并 Q/A 并就地追问，适合围绕单个问题持续阅读；采用 MCP 内嵌界面 | 它能从其支持的原生会话数据建立关系；我们依赖传入快照，无法实现同等实时同步，也没有原生分叉操作 |
| [Chat Branch Visualizer](https://github.com/FuugaMo/chat-branch-visualizer) | ChatGPT/Claude 浏览器侧栏中的分支浏览、消息定位、缩放与快照 | 不依赖聊天网页 DOM 选择器；问题下方直接显示回答，并允许编辑画布关系 | 我们无法直接遍历宿主真实历史分支或跳回聊天中的原消息；该项目的网页集成则依赖页面结构，README 提供相关诊断说明 |
| [GPT Conversation Toolkit](https://github.com/bujue3709/GPT-Conversation-Toolkit) | ChatGPT 网页会话的全文/选中导出、多格式输出、搜索定位、时间线与文件夹管理 | 横向树状结构更突出问题的延续和分支，逐卡片追问更集中 | 我们不提供跨会话文件夹、完整历史采集及 PNG 导出；本次补齐的搜索与 Markdown/JSON 导出仅覆盖传入数据 |

这些工具的运行环境不同。比较的是交互和数据能力，不能把浏览器扩展或 DeepSeek Harness 集成直接视为 ChatGPT 桌面插件的可用能力。

## 已落实到 0.5.0 的优化

1. **让连续性更清楚。** 主线节点优先沿同一水平线展开，分支下移；实线表示主线，虚线表示分支。默认布局不重叠，拖动后可自动整理。
2. **关系判断可解释、可纠正。** 优先采用明确父问题和引用，减少仅因出现“如何”“为什么”或相似词就误判分支的情况。关系面板支持改为主线/分支、选择前置父问题、恢复推断及撤销。它仍是启发式展示关系，不能保证语义判断始终正确。
3. **解决长对话导航。** 折叠分支、全文搜索、上/下一个命中、展开命中路径、定位最新问题，配合固定视口与阅读列表，避免整个窗口无限向下增长。长画布只创建视口附近的卡片。
4. **保护阅读与追问。** 回答内部可滚动，选中正文后可引用；每卡独立追问输入。缩放或切换视图保留草稿，宿主发送失败时保留原输入，发送期间的新输入不会因旧请求成功而被清空。
5. **修复内容丢失。** 同一问题后连续多条回答全部显示，开头没有对应问题的回答独立保留；移除原有 500 条消息上限，不再静默截断传入内容。
6. **新增可带走的备份。** 导出 Markdown/JSON，包含本次传入的文本及画布关系，排除未发送草稿；下载不可用时提供复制文本。

## 追问行为的准确性

旧版尝试使用未确认的元数据将内容放入聊天草稿。本版使用宿主标准 `ui/message` 发送路径，按钮明确标为“发送追问”；收到宿主确认才报告已交给 ChatGPT，不把提交当作回答完成。复制追问仍可用于手动发送。接口依据：[ChatGPT UI 文档](https://developers.openai.com/plugins/build/chatgpt-ui)、[插件参考](https://developers.openai.com/plugins/reference)。

## 验证结果

- 7 项核心测试通过：完整消息保留、稳定节点 ID、关系优先级、显式引用、主线水平布局、无重叠布局及折叠搜索/导出等。
- MCP 本地协议测试通过：初始化、工具发现、版本化界面资源、超过 1,000 条消息完整传递、非法输入处理。
- Edge 无头浏览器模拟宿主测试通过：长文显示、文本选择、草稿、成功/失败发送、关系撤销、折叠搜索、导出、拖动、窄视口和 800 个问题导航；大画布测试中同时创建的卡片少于 30 张。这是功能验证，不是跨设备性能基准。
- 实际渲染截图已检查，见同目录桌面与窄窗口预览图。截图使用示例数据，不是用户完整聊天记录。

## 仍待实际宿主确认的事项

当前交付是 0.5.0 源码与 ZIP，没有自动替换已经安装的远程插件。实际 ChatGPT 宿主中的发送、剪贴板、下载、存储隔离与更新加载需要在安装后确认。测试使用本地模拟宿主，不能据此宣称真实宿主联调已完成。

画布不能自行读取全部历史或流式更新；新增对话需要重新调用工具传入。正文目前是纯文本，尚无完整 Markdown 富文本排版。持久化为尽力保存，不保证跨设备同步；未提供稳定会话 ID 时，相同标题与首问可能共用视图状态。自动分支分类允许人工修正，不代表 ChatGPT 原生分叉。
