# ChatGPT 原生对话便笺画布

这是给 **ChatGPT 桌面版**使用的本地插件（MCP App），不是浏览器扩展。

它通过 ChatGPT 调用工具取得当前对话的用户问题和助手回答，在 ChatGPT 内显示为可拖动、缩放的便笺节点，并支持列表视图。选中问题后输入追问，插件会把包含原问题的内容插入当前 ChatGPT 对话草稿，发送前仍可编辑。

## 在 ChatGPT 桌面版加载

项目内已放置本地插件目录和 marketplace 清单：

- 插件：`.agents/plugins/conversation-canvas/`
- 清单：`.agents/plugins/marketplace.json`

按 OpenAI 的本地插件流程，用 ChatGPT 桌面版打开此项目并重启应用，然后在 Plugins 插件目录的“本地 ChatGPT 插件”来源中安装“对话便笺画布”。若应用没有自动发现项目 marketplace，可在本地插件目录中添加此 marketplace 文件所在目录。

安装后，在新对话中说“把当前对话整理成便笺画布”。插件会将可用的对话轮次传给画布工具并显示。追问会写入当前聊天的可编辑草稿；发送追问并收到回答后，再说“更新对话画布”即可重新映射。

## 对话读取边界

ChatGPT 插件接口不提供自动监听每条新消息或静默读取完整历史的权限。画布数据由 ChatGPT 在用户调用插件或请求更新时传入；调用时模型只能传入它当前可用的对话上下文。插件不向外部服务发送对话内容。拖动布局保存在插件视图本地存储中。
