# 对话便笺画布 · 0.5.0

把传入的对话整理成可拖动的横向树状画布。每张便笺中，问题在上、回答在下，底部可以直接输入追问。此包是包含 MCP 服务和内嵌界面的插件源码包，不是 Chrome 扩展。

## 本版改进

- 主线在同一水平线上延伸，分支在下方展开；默认自动布局避免重叠，手动拖动后可用“自动整理”复位。
- 保留连续多条回答、开头的独立回答和长文本，取消旧版 500 条消息截断。卡片内容独立滚动，界面保持固定视口。
- 每张卡片都有追问框。选中正文后可引用追问，缩放、切换视图时保留输入。点击“发送追问”才向宿主发送；失败时保留输入，也可复制到聊天中发送。
- 按明确来源优先建立关系，弱关联不强行当作分支。用户可修正主线/分支和父问题，也可撤销修正；调整仅影响画布，不修改原聊天。
- 新增分支折叠、全文搜索、结果跳转、定位最新问题。搜索覆盖完整回答与折叠节点，找到结果后展开路径。
- Markdown / JSON 导出传入的消息及展示关系，不包含未发送的草稿。宿主不支持下载时可复制导出文本。
- 仅渲染视口附近的卡片，降低长对话的界面负担；支持窄窗口与阅读列表。

## 使用与更新

在支持此类插件及 MCP Apps 界面的宿主中安装或更新本包后，调用“对话便笺画布”，并说“把当前对话整理成画布”。新增对话后可再次请求刷新。

ZIP 中只有一个 conversation-canvas 根目录。插件身份仍为 conversation-canvas；运行入口和 STDIO 配置见 mcp.json，要求宿主能运行 Node.js。请通过当前宿主提供的插件更新或本地加载流程使用该目录。不同宿主、账号和发布渠道的加载能力不同；解压 ZIP 本身不会更新已安装的远程插件。

## 数据与边界

画布展示的是调用工具时传入的对话快照，不能自行读取全部聊天历史、实时监听新回复或创建 ChatGPT 原生分支。分支自动判断是本地启发式推断，可以人工修正。显示数量代表本次传入的内容，不代表账号内完整历史。

正文以纯文本显示，不执行消息中的 HTML；复杂 Markdown、表格和代码语法暂不提供富文本排版。选取引用时请在同一张卡片的同一段正文区域内选择。

位置、折叠和关系修改会尝试保存在当前浏览环境的本地存储中；追问草稿尝试保存在会话存储及宿主提供的组件状态中。存储可能被宿主禁用或清除，不承诺跨设备同步。未提供稳定会话 ID 时使用标题与首条问题区分会话，重名且首问相同的会话可能共享视图状态；重要内容请导出保存。

“发送追问”通过宿主 ui/message 接口提交带原问题、可选引用与新问题的文本。宿主确认接收不代表已生成回答。当前包通过模拟宿主测试，仍需在实际 ChatGPT 宿主中验证消息提交、剪贴板、下载和持久存储。

## 开发与验证

运行 npm run build，将 core.mjs、ui.js 和 template.html 打包成独立的 app.html；运行 npm run check 检查源码语法。运行时使用 Node.js 内置模块，无额外 npm 依赖。界面资源版本为 map-0.5.0.html，避免沿用旧版缓存。

随本次交付保留的工作区 qa/ 测试涵盖核心关系/布局、MCP 协议和模拟宿主中的浏览器操作；测试不属于插件运行包。
